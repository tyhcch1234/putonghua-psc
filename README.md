# 普通話水平測試 · 由零開始

一個純靜態的 PSC（普通話水平測試）自學網站：教學、練習、測驗、模擬考試，全部在瀏覽器內完成，無需伺服器、無需登入。

## 內容

| 模組 | 內容 |
|---|---|
| 0 | 考試結構、五個部分、等級標準、備考策略 |
| 1 | 語音基礎：21 聲母、39 韻母、四聲與輕聲、標調與拼寫規則 |
| 2 | 粵語母語者十組難點音矯正、變調規則、每日口腔練習 |
| 3 | 卷一：讀單音節字詞（10 分）— 易錯字表、80 字練習、20 題測驗 |
| 4 | 卷二：讀多音節詞語（20 分）— 變調／輕聲／兒化、50 詞練習、15 題測驗 |
| 5 | 卷三：選擇判斷（10 分）— 粵普詞彙對照、量詞表、語序對照、20 題測驗 |
| 6 | 卷四：朗讀短文（30 分）— 50 篇篇目、五步準備法、示範、10 題測驗 |
| 7 | 卷五：命題說話（30 分）— 三段結構、避坑、素材、50 則話題與切入點、10 題測驗 |
| 8 | 考試日流程、錄音細節、意外補救、心態 |

另有 **60 天學習計劃** 與 **模擬考試**（五部分自評計分、估算等級）。

## 考試依據

依《普通話水平測試實施綱要》（2021 年版，2024 年 1 月 1 日起實施）：

- 卷一 讀單音節字詞：100 音節，10 分，3.5 分鐘
- 卷二 讀多音節詞語：50 詞／100 音節，20 分，2.5 分鐘
- 卷三 選擇判斷：10 分，3 分鐘
- 卷四 朗讀短文：1 篇／400 音節，30 分，4 分鐘（50 篇）
- 卷五 命題說話：3 分鐘，30 分（50 則）

等級：一甲 97+、一乙 92+、二甲 87+、二乙 80+、三甲 70+、三乙 60+。

## 技術

- 純 HTML / CSS / JavaScript，無建置步驟、無外部依賴
- **發音元件**：`assets/js/audio.js` + 站內音檔 `assets/audio/*.mp3`（253 條，約 1.3 MB，普通話女聲），
  點字即發聲，毋須裝置安裝中文語音；頁首 🔊 可切換 1.0×／0.7× 慢速示範（保持原音高）。
  只有音檔載入失敗時才退回瀏覽器 `SpeechSynthesis`（zh-CN）。
- 學習進度與測驗分數存於 `localStorage`，不上傳
- 支援手機、平板、桌面；可直接列印

### 重新產生發音音檔

改了字表或詞表之後（需要網絡與 `pip install edge-tts opencc-python-reimplemented`）：

```bash
node _build/extract_texts.js     # 抽出所有 data-say 文字 → _build/texts.json
python3 _build/gen_audio.py      # 逐條合成 assets/audio/<hash>.mp3 並更新 audio-pack.js
python3 _build/trim_audio.py     # 剪掉頭尾靜音（需要 ffmpeg，可用 npx ffmpeg-static）
```

`_build/test_site.js` 會在 jsdom 內載入整個網站，檢查每條 `data-say` 都有對應音檔、點擊能觸發播放。
